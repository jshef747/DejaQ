# 10,000-Pair Typo Resilience Test

**Status: APPROVED** - User approved verbally on 2026-07-16

## Goal
Create a deterministic test that generates 10,000 query pairs and runs them through `lexical_match.align()` without any server or model dependency.

## What to create

### File: `server/tests/test_typo_resilience.py`

A standalone test file with:

**Pair split (10,000 total):**
- 7,000 typo pairs — realistic typo intensity based on normal typing
- 3,000 sibling pairs — safety rejection testing

**Realistic typo intensity:**
- ~60% with 1-2 typos (normal typing)
- ~25% with 3-4 typos (fast typing)
- ~15% with 5+ typos (edge stress test)

**Expanded templates (38 total, up from 28):**
- Factual/geography: 12 templates
- Science: 10 templates
- Coding/tech: 10 templates
- Practical/daily life: 8 templates
- Culture/history: 8 templates
- Finance/business: 6 templates
- Very long queries: 12 templates (25-40 words)

**Report output: `docs/typo-resilience-report.md`**
- Overall recall / rejection rates
- Recall by intensity tier and length tier
- Heatmap: intensity x length -> recall
- Recall by mutation type and domain
- Breaking point analysis
- All failure cases listed
- Comparison to existing 1,500-pair results

**Pytest assertions:**
- Typo recall >= 95% overall
- Typo recall >= 98% light intensity
- Typo recall >= 90% medium intensity
- Typo recall >= 80% heavy intensity
- Typo recall >= 95% short queries
- Typo recall >= 93% medium queries
- Typo recall >= 90% long queries
- Typo recall >= 85% very long queries
- Sibling rejection = 100% hard-zero safety
- Distribution verification (intensity + length)

**How to run:**
```bash
cd server && uv run pytest tests/test_typo_resilience.py -v
cd server && uv run python tests/test_typo_resilience.py  # writes report
```
